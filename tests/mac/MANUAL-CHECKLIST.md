## 0. 怎么记录

每一项结尾都有：

```
记录：☐ 通过　☐ 失败　☐ 无法执行　证据：________
```

- **通过**：实际行为与预期一致。
- **失败**：能稳定复现的偏差。请在同一行写清"实际发生了什么"。
- **无法执行**：前置条件不满足（没有触控板、没有 7z 文件、没有工作区等）。不要为了凑通过而勾选。
- 证据命名：`ID-序号.png`，例如 `KEY-07-1.png`、`UI-01-1.png`。录屏命名 `ID.mov`。
- 失败时至少提供：截图 + 控制台报错（若有）+ 探针 JSON（若涉及键盘/手势/拖拽）。

### 严重度（写进报告模板时用）

| 级别 | 含义 | 例子 |
| --- | --- | --- |
| **P0 阻断** | 无法安装/打开/保存，丢数据，假成功 | 画布永久白屏；运行显示完成但实际没执行；撤销删错文件 |
| **P1 严重** | 核心流程失败或键盘被抢，但有绕行 | 中文选词误删节点；Finder 拖拽完全无反应；导入中文路径失败 |
| **P2 一般** | 手势/菜单/布局体验问题，有绕行 | 双指滚动误缩放；右键菜单出屏；toast 被遮 |
| **P3 建议** | 文案、对齐、性能、可访问性 | 图标不齐；长项目名截断难看 |

### 测试数据准备

在 `~/Desktop` 建一个 **测试专用** 文件夹，不要用真实项目：

```bash
BASE="$HOME/Desktop/CodeFlow 测试"
mkdir -p "$BASE/项目 甲/src" "$BASE/项目 甲/docs" "$BASE/项目 甲/tests"

cat > "$BASE/项目 甲/src/用户模块.js" <<'EOF'
/** 用户模块：注册与登录。 */
// TODO: 修复中文用户名规范化
export function createUser(name) { return { name } }
EOF

cat > "$BASE/项目 甲/src/订单 处理.py" <<'EOF'
"""订单处理：TODO 支持多币种。"""
def total(items): return sum(i.get("price", 0) for i in items)
EOF

cat > "$BASE/项目 甲/docs/设计.md" <<'EOF'
# 设计
- 用户模块：`src/用户模块.js`
EOF

cat > "$BASE/项目 甲/tests/test_用户.py" <<'EOF'
def test_placeholder(): assert True
EOF

# NFD 文件名（在 Finder 里手动输入 café 也行）
touch "$BASE/项目 甲/src/café 笔记.txt"
touch "$BASE/项目 甲/src/带 空格 #与% 的模块.js"

# 复制一份用于路径测试
cp -R "$BASE/项目 甲" "$BASE/项目 乙"

# Finder 压缩包（也会产生 __MACOSX）
ditto -c -k --sequesterRsrc --keepParent "$BASE/项目 甲" "$BASE/项目 甲.zip"

# tar.gz
tar -czf "$BASE/项目 甲.tar.gz" -C "$BASE" "项目 甲"
```

可选：用 Keka / 7-Zip 生成一个 `.7z` 和一个 `.rar`；准备一个含 1200 个小文件的目录（`DRP-11`）：

```bash
mkdir -p "$BASE/大目录"; for i in $(seq 1 1200); do echo x > "$BASE/大目录/f$i.js"; done
```

### 探针准备（涉及键盘/手势/拖拽时）

1. 打开 DSH，切到 CodeFlow 面板；
2. `⌘⌥I` 打开 DevTools → Console；
3. 若提示 `Don't paste code`，先输入 `allow pasting` 回车；
4. 粘贴 `console-probe.js` 全部内容；
5. 运行 `CodeFlowProbe.ui()` 记录首屏诊断；
6. 运行 `CodeFlowProbe.start()`；
7. 做完相关用例后运行 `CodeFlowProbe.download()`，把文件改名成 `probe-<组>.json`。

> 探针在主窗口或画布 iframe 的 Console 都能用；它会自动找同源的 CodeFlow iframe。

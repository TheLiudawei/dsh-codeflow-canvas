## 6. 已经确认的 macOS 平台问题（勾选你复现到的）

- [ ] Finder「压缩」出来的 zip 导入后出现 `__MACOSX/._*` / `.DS_Store` 节点（`ARC-03` / `DRP-02`）
- [ ] 拖入 `.7z` / `.rar` 提示没有解压器（`ARC-10` / `DRP-04`）
- [ ] 双指滚动会缩放，且容易缩放过头（`RISK-03` / `TRK-01`）
- [ ] 纯横向双指滚动也会缩放（`TRK-03`）
- [ ] 中文输入法选词时画布有反应（`RISK-02` / `KEY-07`）
- [ ] ⌘Z 不能撤销，只有 Control+Option+Z（`RISK-04` / `KEY-11`）
- [ ] 只有 `.DS_Store` 的文件夹被当成项目根（`ARC-06`）
- [ ] CLI `--json` 导入没有生成模块图（`IMP-10`，脚本用户）

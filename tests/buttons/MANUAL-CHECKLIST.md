# CodeFlow 画布按钮 · 手工验收清单（v1.2.2，需求一 C 层）

> 与 `tests/buttons.mjs`（A 层静态审计）、`tests/buttons/canvas-selftest.js`
> （B 层真实点击）互补：C 层覆盖需要真实项目、真实权限或破坏性确认的路径。
> 逐项填写「实际结果」与「通过 / 失败 / 无法执行」；`expected` 一栏写的是
> **可观察**结果（modal 出现、请求发出、按钮状态变化），不是实现细节。
>
> 前置：DSH 已安装本版插件；打开一个**测试项目**（建议含模块结构图）；
> DevTools Network 面板过滤 `codeflow/api` 以便核对请求。

图例：结果栏可选 `✅ 通过` / `❌ 失败` / `➖ 无法执行（写原因）`。
